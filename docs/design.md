# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は、夜の高架下に貼られた蛍光のポスターが、スクロールすると暴れ出して、靴が飛び出してくるように見える。**

- 架空ブランド **GRAVLESS（グラブレス）** の新作 **PULSAR-9（パルサー・ナイン）** の発売ページ。一言「地面を、蹴り返せ。」
- 発売 2026.12.12（土）10:00 JST、¥24,800（税込）、数量限定 1,212 足、先着順・1人1足・公式オンラインと東京・大阪の2店。
- 文字が主役。巨大な欧文が画面の端からはみ出し、区画ごとに地と文字の2色の組を切り替えて、色をぶつける。
- 靴は写真を使わず、three.js でパーツから組んだ 3D。1枚の WebGL が画面に固定され、靴は区画の「置き場」を渡り歩く。
- 実在のブランドの名前・ロゴ・形（3本線や特定の曲線）は使わない。靴の側面の印は「脈拍の波」（PULSAR から）。

## 参考にした実例（`factory-refs/board.md`・`factory-refs/shots/`）

- NOVASELL https://novasell.com/ ：幅いっぱいの超長体の欧文。蛍光の地に黒だけの2色。黒帯に抜いた太い和文。巨大文字と小さい和文の大きさの差。
- Lusion https://lusion.co/ ：単純な形の3Dを、艶と強いハイライトで高級に見せる。
- adidas Originals: Ozweego 2048（Awwwards SOTD、Jam3）：靴を真ん中に浮かべて展示物にし、小さな蛍光の HUD 表記を添える。
- Active Theory https://activetheory.net/ ：暗い地に奥行きのある粒。
- Exo Ape https://www.exoape.com/ ：巨大な見出しを画面の端で切る。
- SANKOU!「蛍光色」の一覧（X GROUP、PIXEL×PIXEL など）：黒×蛍光黄緑の立体、補色どうしをそのままぶつける配色。

## 色

| 名前 | hex | 用途 |
|---|---|---|
| 黒 | `#0A0A0B` | 地。黄緑・ピンク地の上の文字 |
| 白 | `#F4F4EE` | 黒地・青地の上の文字 |
| 灰 | `#B8B8B0` | 黒地の上の小さな補足（注意書き・ラベル） |
| 蛍光黄緑 ACID LIME | `#C8FF00` | 差し色（最初の色違い）。ピンク色違いのソール |
| 蛍光ピンク SHOCK PINK | `#FF2E9A` | 差し色（2つ目の色違い）。見どころ02の地。入力の誤りの文字と枠 |
| 電気青 VOLT BLUE | `#2B3BFF` | 差し色（3つ目の色違い）の塗り。見どころ03の地 |
| 淡い青 | `#9AA3FF` | VOLT BLUE を選んだときの、黒地の上の差し色の文字（青そのままは黒地で 3:1 に届かない） |
| 信号オレンジ | `#FF5A1F` | VOLT BLUE の色違いのソールと、そのときのぶつけ色 |
| 入力欄の仮の文字 | `#8A8A84` | placeholder だけ |

- 差し色は CSS 変数で切り替わる：`--accent`（塗り）、`--accent-ink`（塗りの上の文字。青のときだけ白、ほかは黒）、`--accent-text`（黒地の上の差し色の文字）、`--clash`（差し色にぶつける色。黄緑→ピンク、ピンク→黄緑、青→オレンジ）。値は `src/lib/colorways.ts` と `globals.css` の `[data-colorway]`。
- 組み合わせは「黒地×差し色の文字／白」「差し色の塗り×accent-ink」「ピンク地×黒」「青地×白」「clash 地×黒」だけ。全部 4.5:1 以上。
- 背景にグラデーションは使わない。例外はヒーローの、差し色を 22% 混ぜた中央の円い光（`radial-gradient`）と、4px おきの細い横縞だけ。

## 文字

| 役 | 書体（next/font/google） | 大きさ | 行間・字間 |
|---|---|---|---|
| 巨大欧文（ヒーロー・見どころの単語・色の名前・数字・フッター） | Anton 400 | 15vw〜40vw。画面幅いっぱい、はみ出してよい | 0.8〜0.86、-0.01em。全部大文字 |
| 和文の見出し・帯 | Dela Gothic One 400 | 見出し `clamp(44px, 6.4vw, 104px)`、見どころ `clamp(40px, 5vw, 80px)`、帯 `clamp(36px, 5.6vw, 92px)` | 1.08〜1.12 |
| 本文 | Noto Sans JP 500/700 | 16px（リード 18px、注意書き 14px） | 1.8 |
| HUD（小さな表記・ラベル） | Space Mono 700（日本語は Noto Sans JP に落ちる） | 12〜14px | 1.5、0.08em、大文字 |

- 巨大な数字（見どころの数値・カウントダウン）は Anton。単位は Space Mono で 0.24em。
- 文言は日本語。欧文は HUD・単語の見出しと商品名・色名だけ。

## グリッドと余白

- 左右の余白 `--pad`：PC 24px／スマホ（720px 以下）16px。巨大文字は余白を無視して端から端。
- PC の見どころ・通知は 12 列（間 24px）。文は 5〜7 列、靴の置き場は残り。見どころ02 は左右を入れ替える。
- 900px 以下は1列。靴の置き場を上、文を下。
- 区画の上下：PC 96〜120px、スマホ 72〜88px。本文の幅は最大 34em。
- 固定ヘッダーの高さ `--header-h`：PC 64px／スマホ 60px。

## 部品

- **ヘッダー**：黒地、下に差し色の 2px 線。左にロゴ（Anton 30px「GRAVLESS」）、右に点滅する差し色の点＋「DROP 2026.12.12 10:00 JST」（スマホでは隠す）、差し色の丸いボタン「通知を受け取る」（#notify へ）。
- **ボタン**：高さ 44px 以上。差し色の塗り（`btn-accent`）は丸（999px）、通知の送信は角ばった高さ 64px（`btn-big`）。押すと 0.97 に縮む。hover（hover できる機器だけ）で白地・黒文字。
- **帯（band）**：Dela Gothic の和文を差し色の塗りに抜く。1行ずつ箱にして、2行目を右へずらす。
- **マーキー**：差し色（-4°）と clash 色（+3°）の2本の帯が交差して、逆向きに流れる。Anton と Dela Gothic を交互、区切りは ✦。
- **見どころ**：3つ。01 黒地（単語は差し色）、02 ピンク地（黒）、03 青地（白・縁取りは黄緑）。巨大な単語の後ろに同じ単語の縁取り（2px）を続ける。番号は HUD「01 / 03 — BOUNCE」、数値は上に 2px の線。
- **色違いのボタン**：3つ並び（スマホは縦）。角なしの四角、2px の枠はその色。左に色とソールの色を半分ずつの丸（-30°）。選ぶと塗りつぶし。`aria-pressed`。下に「NOW — 色名：一言」。
- **カウントダウン**：clash 色の地に黒の Anton の数字（`--` から始めて、ブラウザで1秒ごとに数える）。各数字の上に 4px の線、下に「DAYS 日」。下に黒い帯で購入の決まり3つ（HOW / LIMIT / WHERE）。発売を過ぎたら見出しは「発売中。」。
- **通知の入力**：白い 2px の枠の入力欄（高さ 64px）＋差し色の送信ボタンが横につながる（520px 以下は縦）。誤りはピンクの枠と文。受け付けると差し色の枠の箱で「受け付けました。」。見本なので送らない旨を必ず添える。
- **フッター**：差し色の地に、幅いっぱいの「GRAVLESS」。架空のブランドである旨を書く。

## 3D（`src/components/shoe/`）

- 靴は側面の形（中底・外底・アッパー・マッドガード・ヒールカウンター）を `ExtrudeGeometry` で押し出し、前後と高さで幅を絞って作る。紐・ベロ・かかとのつまみ・側面の脈拍の波・かかとの光るクッションを重ねる。
- 材質：アッパーは半艶、中底・外底・差し色の部品はクリアコートの艶。環境光は `RoomEnvironment`。トーンマップは `NeutralToneMapping`（蛍光が褪せない）。
- 光：上から白、左にピンク、右に青の点光源。足元に差し色の輪が2本回る。白と差し色の粒が奥行きを持って漂う（スマホは半分）。
- 置き場：`data-shoe-slot` を持つ空の箱。`data-rx` `data-ry` `data-rz`（向き、ラジアン）と `data-spin`（0〜1、回り続ける強さ）。靴は置き場の大きさ（幅か高さ×1.7 の小さい方）の 90% の長さになる。新しい区画に靴を出すときは、置き場を足すだけ。
- 色違いを選ぶと、靴の色・輪・粒が 0.3 秒ほどで寄り、靴が一瞬ふくらむ。
- 解像度はスマホ 1.5 倍・PC 1.75 倍まで。スマホでは antialias なし。タブが隠れたら止める。

### WebGL が使えないとき（`ShoeSideSvg`）

- 置き場に、靴の側面1方向の平面イラスト（SVG）を出す。形は 3D の側面の形（外底・中底・アッパー・ヒールカウンター）と同じで、つま先は右。
- 塗りは色違いの `shoe` だけ：アッパー＝upper、中底＝midsole、外底とヒールカウンター＝outsole、側面の「脈拍の波」（太さ 0.13 の折れ線）＝trim。
- 影・グラデーション・縁取りは使わない。実在ブランドの線・ロゴは使わない。回さず、動かさない。
- 置き場の幅と高さの 90% に収め、中央に置く（縦横比は保つ）。

## 動き

- 靴：置き場の近くでは置き場と一緒に流れ、置き場の間の 30〜70% で次の置き場へ向き・大きさごと移る。ヒーローではゆっくり回る。マウスで少し傾き、スクロールの速さで少し傾く。最初は 1 秒で大きくなって出てくる。
- 巨大な単語：スクロールに合わせて左右に流れる（GSAP ScrollTrigger の scrub、`data-scrub-x`）。ヒーローの「PULSAR」と「-9」は、スクロールで左右に割れて流れる。
- 見出し：画面の下 12% に入ったら、下から 0.5 秒で出る。
- マーキー：CSS で 22 秒・28 秒で一周。
- 動かすのは transform と opacity だけ。pin（固定してスクロールを奪う）はしない。
- `prefers-reduced-motion: reduce`：GSAP の動き・マーキー・点滅・色の名前の出方を止める。靴は回らず、揺れず、粒も止まり、置き場にそのまま付く（ページと一緒に流れるだけ）。描くのはスクロールと色替えのときだけ。

## 写真

- 使わない。靴は 3D、ほかは文字と色で見せる。

## 避けること

- 3色以上を1つの区画の地と文字に使う（地と文字は2色の組。3色目は差し色の小物だけ）。
- 角の丸い四角のカード、影（box-shadow）でのせる表現、細い書体の大きな見出し。
- 黒地に VOLT BLUE（`#2B3BFF`）そのままの文字（淡い青 `#9AA3FF` を使う）。
- 実在のブランドを思わせる線・ロゴ・配色の組み合わせ。
